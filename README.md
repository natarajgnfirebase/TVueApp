### Adding images
To update the images library, complete the following:
1. prepare images by resizing and optimizing appropriately
2. place the new images into the relevant `assets/images/admin-sys/` subdirectory
3. run `cd src/scripts && node image-sizes.mjs` – this will regenerate the image JSON data
4. recompile the Vue app
